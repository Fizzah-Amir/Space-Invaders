# 🚀 Space Invaders Game (Python + Pygame)

A classic **Space Invaders arcade game** built using **Python and Pygame**.  
The player controls a spacecraft, moves left and right, and shoots bullets to destroy enemies. The game includes keyboard controls, sprite rendering, background graphics, and basic enemy movement logic.

---

## 🎮 Game Preview

A simple 2D space shooter where:

- 🚀 Player controls a spacecraft
- 👾 Enemy spacecraft moves horizontally
- 🔫 Bullets are fired using the space key
- 🌌 Background image creates a space environment
- ⌨️ Keyboard events control player movement

---

## ✨ Features

### Player System
- Player spaceship rendering using image sprites
- Smooth left/right movement
- Boundary collision handling to keep the player inside the screen

### Enemy System
- Random enemy starting position
- Horizontal enemy movement
- Enemy direction changes when reaching screen boundaries

### Shooting Mechanism
- Space key shooting controls
- Bullet sprite rendering
- Bullet movement system
- Bullet state management (`ready` / `fire`)

### Graphics
- Custom background image
- Custom spaceship icon
- Sprite-based game objects
- Real-time rendering using Pygame display system

## 🎮 Controls

| Key | Action |
|-----|--------|

| ➡️ Right Arrow | Move spaceship right |
| SPACE | Fire bullets |
| ❌ Close Window | Exit game |
